## Overview

Tap Kingdom（拇指群雄）的視覺語言以**漆器、青銅、朱印、軍令**為意象，目標是在快節奏單指操作下仍保有三国題材的威儀感，而非西方 arcade brawl 的廉價霓虹風。

品牌個性：威儀而不沉重；資訊清晰、層級分明；文案半文言、短句、軍事語感。

### UI 分層（Tier）

| Tier | 名稱 | 代表畫面 | 閱讀節奏 | 主軸參考 |
|------|------|----------|----------|----------|
| T1 | 品牌／選單層 | Hub、選角、設定 | 慢 | characterSelect + uiTheme |
| T2 | 決策／暫停層 | Rogue 三選一、結算面板 | 中 | tk-panel / tk-card |
| T3 | 戰場 HUD 層 | 血條、計分條、mission bar | 快（≤0.5s） | scoreManager live-hud |
| T4 | 宣告／時刻層 | 波次 banner、回合 announcer | 瞬間 | announcer presets |

**原則**：T1 定品牌與 token；T3/T4 共用 token，但不照搬 T1 的 panel 厚重邊框造型。

### 實作對應

- **Normative CSS 實作**：`uiTheme.js`（`:root` 變數 + 共用 class）
- **本文件**：設計 rationale、文案、語意角色；Phase 1 起新 UI 須引用 token，禁止硬編 hex

## Colors

### 語意角色

| Token | 用途 |
|-------|------|
| `ink` / `lacquer` | 底色、overlay、漆器深墨 |
| `bronze` / `gold` | 邊框、標題、軍餉、accent |
| `seal` | 一屏唯一主行動、危險、開戰瞬間 |
| `text` / `text-muted` / `text-sub` | 正文三級 |
| `faction-*` | **陣營識別**（魏蜀吳群武將、卡牌 accent、羈絆） |
| `team-blue` / `team-red` | **連線對戰隊伍色**（與 faction 語意獨立；現值碰巧與魏藍、吳紅同色） |
| `combat-me/ally/enemy` | 戰場血條／關係色（不替代 faction 色） |

### faction-wei 目前用在哪裡

| 位置 | 檔案 | 現值 | 用途 |
|------|------|------|------|
| CSS token | `uiTheme.js` | `#1E88E5` | `--tk-faction-wei`；操作說明 PC 區塊邊框／標題色 |
| 選角 | `characterSelect.js` | `#1E88E5` | 魏武將（曹操、張遼）卡牌左側 accent |
| Rogue | `rogueDirector.js` | `#2b6ba3` ⚠️ | 招募卡、羈絆 banner、軍團 chip 邊框 — **與 uiTheme 不一致** |
| 詞條流派 | `wordConfig.js` | `#2b6ba3` | 「守」系字印色 — 與 rogueDirector 魏色連動 |

**決策**：`faction-wei` 以 `#1E88E5`（uiTheme / 選角）為準；Phase 1 將 `rogueDirector.factionColor.wei` 與 `wordConfig` 對齊。  
**連線隊伍**：使用獨立 `team-blue` / `team-red` token（現值 `#1E88E5` / `#E53935`），語意上不視為魏／吳 faction 色，僅數值碰巧相同。

### team-blue / team-red 目前用在哪裡

| 位置 | 用途 |
|------|------|
| `characterSelect.js` | 房間大廳玩家列表邊框 |
| `gameModeManager.js` | Bounty 倒數 UI、announcer `.text-blue` / `.text-red` |
| `scoreManager.js` | 3v3 計分條我方／敵方數字色 |

## Layout

- **Base unit**：8px（半階 4px 僅 micro-adjust）
- **Hub**：panel max 560px；content column max 400px
- **Safe area**：`env(safe-area-inset-*)`
- **Mission bar**：位於計分條（`#live-score-bar`）正下方；Rogue 為 `#rogue-hud` 頂列下方之 `rg-hud-obj`
- **HUD 頂列**：波次／計分列永遠單行（`white-space: nowrap`）；極窄螢幕允許波次文字 ellipsis

### Hub 流程（已定）

- **單人出征**：維持 A — Hub → 選陣 → 群雄集結 → 選角
- **征／戰視覺層級**：待定（是否 primary／secondary 分化）

## Elevation & Depth

- **T1/T2**：tonal layers + bronze border glow；避免厚重 drop shadow
- **T3**：血條黑底 + 細邊；不用 panel 級 2px bronze 外框
- **T4**：banner 型（頂部窄條）或 fullscreen 型（半透明 overlay + serif 大字）

## Voice & Copy Guide

### 語氣

- 主語言：繁體中文，半文言、短句
- 禁止：完整英文句、英文詞綴名、Anton italic + UPPERCASE 英文 announcer

### 允許的英文

模式縮寫 `3V3`、`FFA`、`ROGUE`；品牌副標 `TAP KINGDOM`；HUD 縮寫 `Lv`、`K`（空間極窄時）

### 標點

- 標題副標：` — `（全形破折號，前後空格）
- Banner 合併：` · `
- 詞綴疊加：`鐵壁·驍勇·關羽`

### 詞綴中文化（normative）

| key | 中文名 |
|-----|--------|
| tough | 鐵壁 |
| fierce | 驍勇 |
| swift | 疾行 |
| rage | **狂暴** |
| giant | 巨軀 |
| — (Boss) | 天公將軍 |

顯示：`{詞綴}·{武將名}`；詞綴色 `--tk-gold`

### Preset B — 回合／勝負 fullscreen（已定）

| 現況（廢） | 採用 |
|-----------|------|
| ROUND {n} OVER | **回合 {n} 結束**（阿拉伯數字） |
| BLUE TEAM WINS | **我軍勝利** |
| RED TEAM WINS | **敵軍獲勝** |
| BATTLE! | **開戰！** |
| YOU DIED | **你已陣亡** |

平局、時間到等句式 Phase 1 實作時比照此語氣補齊（如「平局」「時刻已盡」）。

### Preset D — 結算畫面（已定）

| 現況（廢） | 採用 |
|-----------|------|
| VICTORY | **勝利** |
| BACK TO MENU | **回營** |

其餘結算標題（失利、平局、排行榜）Phase 1 比照「勝利／回營」語氣中文化。

### Preset E — Kill Feed（已定）

格式：**[擊殺者 ID] [武器/技能 Icon] [被擊殺者 ID]**

- 中間為圖示，兩側為玩家／武將顯示名
- 不用英文 `eliminated`、`KO`

波次 announce、陣亡、復活、羈絆等沿用 `rogueDirector` 現有中文模板與 `目標：` 前綴。

## Do's and Don'ts

### Do

- 新 UI 引用 `var(--tk-*)` 或 `{colors.*}` token
- 一屏一個主行動（`seal` / `gold` 級）
- faction 色與 team 色語意分開；允許 hex 相同但 token 名不同
- 戰場數字用 Anton；mission／announcer 中文用 body 或 serif
- 頂列 HUD 永遠單行

### Don't

- 在 feature script 內 `createElement('style')` 寫死色值（Phase 1 清理既有違規）
- 使用 `#FFD700` 純金（用 `--tk-gold`）
- Anton italic + 全大寫英文 announcer
- 英文詞綴（Ironclad 等）
