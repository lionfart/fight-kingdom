# Rogue 新卡想法備忘（未實作）

記錄日期：2026-07-17  
來源：設計討論表（破綻／餘燼／逆鱗／風返／連鎖收割／淨域／共鳴）  
狀態：僅備忘，未寫入 `wordConfig.js`

---

## 總則

目標：讓各學派有「可感知的循環／收尾」，減少純小數乘算與 good-stuff 四張拼盤。  
實作前建議：先定每條線的**入口卡**（符咒／幻影／獵首／銅牆），新卡當**第二格高潮**，不要再變啟動稅。

---

## 新卡列表

### 1. 破綻（武 / N）

| 欄位 | 內容 |
|------|------|
| 效果概念 | 連段、減速或破盾後給目標上「破綻」標記；下一次爆擊或重擊消耗標記，造成爆發傷害 |
| 解決什麼 | 武系有「布置 → 爆發」節奏，不只常駐加攻 |
| 實作難度 | **中高** |
| 依賴 | 目標標記（新 debuff／flag）；掛點：連段末、snare、shieldBroken；消耗點：crit 或「重擊」定義（建議固定 comboIndex===2） |
| 現有基礎 | `onCrit`、`shieldBroken`、`applyDebuff` 可延伸 |
| 風險 | 「重擊」若定義不清會難調；標記 UI 最好有浮字／圖示 |

### 2. 餘燼爆裂（術 / R）

| 欄位 | 內容 |
|------|------|
| 效果概念 | 攻擊「滿層灼燒／符印」目標時觸發爆炸，並濺射周圍 |
| 解決什麼 | DoT／符咒線有明確收尾 |
| 實作難度 | **中高**（若堅持「滿層」）；**中**（若簡化成「身上有 burn 則機率／CD 爆炸」） |
| 依賴 | 爆炸／濺射（可借 explode／小範圍傷害）；「滿層」需 DoT stack 系統（現況同 type 覆蓋、不疊層） |
| 現有基礎 | burn／flame／inferno 可並存（不同 type）；符咒 `onBasicProc`+dot |
| 風險 | 未做 stack 前，「滿層」無法誠實實作 → 建議 v1 用「有灼燒」+ 內置 CD |

### 3. 逆鱗反擊（守 / R）

| 欄位 | 內容 |
|------|------|
| 效果概念 | 護盾吸收達閾或護盾破碎時觸發：下一次攻擊變反擊（擊退）並短時減傷 |
| 解決什麼 | 守系能把防轉攻，對標獵首類進攻卡的存在感 |
| 實作難度 | **中** |
| 依賴 | 護盾吸收累計或 `shieldBroken` 事件；攻擊者「下次攻擊」旗標；短時 `damageTakenMul` |
| 現有基礎 | `CombatResolver` 已有 `shieldBroken`、`onShieldBreakDmgPct`；擊退在 hitMeta |
| 風險 | 全軍護盾時「誰觸發／誰吃反擊」要定規則（建議：僅玩家／持卡單位） |

### 4. 風返（疾 / N）

| 欄位 | 內容 |
|------|------|
| 效果概念 | 成功閃避疊 1 層「風跡」；3 層時下一次攻擊獲得貫穿或追擊 |
| 解決什麼 | 閃避從堆%變成「閃了有下文」的主動循環 |
| 實作難度 | **中** |
| 依賴 | `tryDodgeIncoming` 成功回呼加層；3 層消耗改寫下一發（pierce 或短暫追蹤／加傷） |
| 現有基礎 | 閃避判定已有；`pierce` 攻擊模式已有 |
| 風險 | 「追擊」語意要定（自動鎖近敵？傷害加成？）；層數 UI |

### 5. 連鎖收割（武 / R）

| 欄位 | 內容 |
|------|------|
| 效果概念 | 斬殺或擊殺後，自動將下一個目標掛上斬殺印／短時標記 |
| 解決什麼 | 獵首流專精清波，與「萬金油獵首」分工 |
| 實作難度 | **低～中** |
| 依賴 | `onKill`／execute 觸發後找最近敵人上 mark 或短暫 execute 易傷 |
| 現有基礎 | `onKill`、`execute`、冷卻表已有 |
| 風險 | 與獵首過疊會太強 → 建議互斥或「有獵首時強化連鎖」二選一 |

### 6. 淨域（守 / N 或 SR）

| 欄位 | 內容 |
|------|------|
| 效果概念 | 週期清除自身異常（減速／灼燒／控場），或把清除轉成小護盾 |
| 解決什麼 | 守系選項不只減傷％與閃避 |
| 實作難度 | **中** |
| 依賴 | 玩家 `activeStates`／stun／snare 清除 API；週期 timer；`grantShield` |
| 現有基礎 | 護盾 API 有；玩家異常狀態路徑需盤點是否夠多 |
| 風險 | Rogue 若敵人少掛 DoT／CC 給玩家，體感弱 → 需配遭遇或提高價值（轉盾） |

### 7. 共鳴（通用 / N）

| 欄位 | 內容 |
|------|------|
| 效果概念 | 持有同學派 2 張卡時，該派核心機制微幅強化；每局只能選一張共鳴 |
| 解決什麼 | 鼓勵 2 卡學派，而不是四張各拿最強散件 |
| 實作難度 | **低～中（程式）／高（數值與文案）** |
| 依賴 | 依 `faction`（武守疾術）計 owned；`exclusiveGroup: resonance`；對應流派小 buff 表 |
| 現有基礎 | `computeBuffs`／squad 計數模式可抄 |
| 風險 | 「核心機制」每派要寫死且可調；與本命／羈絆疊加要防爆炸；選卡 UI 要標「已有 1/2」 |

## 實作難度一覽

| 新卡 | 難度 | 建議順序 |
|------|------|----------|
| 連鎖收割 | 低～中 | 可先做（掛現有 onKill） |
| 共鳴 | 低～中 | 可早做（純資料驅動），但要先定四派加成表 |
| 逆鱗反擊 | 中 | 接 shieldBroken |
| 風返 | 中 | 接 dodge 成功 |
| 淨域 | 中 | 視玩家異常狀態豐富度 |
| 破綻 | 中高 | 需通用「標記→消耗」框架 |
| 餘燼爆裂 | 中高 | 先做「有灼燒→爆炸」；滿層等 DoT stack |

## 建議共用基建（做 2 張以上標記類卡時值得抽）

1. **目標標記** `mark: { id, duration, onConsume }`（破綻、連鎖收割共用）  
2. **攻擊者下次攻擊修飾** `nextHitMods`（逆鱗、風返共用）  
3. **資源層數** `stacks` + 上限（風返；將來 DoT 層也可共用）  

有這三塊，後面加「布置／反擊／閃避循環」會便宜很多。

## 與現有討論的銜接（勿忘）

- 術系：追符／散符仍建議改精煉，不另佔格；餘燼是**收尾**，不是第三張稅  
- 疾系：風返前最好先處理風幕＋幻影鋒疊閃  
- 守系：銅牆入口＋逆鱗／淨域，才有完整線  
- 武系：獵首入口＋破綻或連鎖，二選一當第二格高潮  

更新此檔時請改「狀態」列，實作進 `wordConfig` 後可把對應條目標成 `done`。
