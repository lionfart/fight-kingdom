## 下次接著做（Phase 2 部署）

### 1. Supabase Secrets

Dashboard：**左側 Edge Functions（或 Functions）→ Secrets 分頁**  
（不在 Project Settings 齒輪裡）

直連（REF 換成你的）：

```text
https://supabase.com/dashboard/project/<PROJECT_REF>/functions/secrets
```

你的專案 URL 若是 `nyqjjsuzxwxufauqoqvw.supabase.co`，REF 多半是：

```text
nyqjjsuzxwxufauqoqvw
```

新增：

```text
STRIPE_SECRET_KEY=sk_test_...
CHARACTER_PASS_PRICE_ID=price_1TucdGIe5ZqA9rXhhXYsavB1
```

`STRIPE_WEBHOOK_SECRET` 等 webhook 建好再加。

找不到 Secrets UI 時用 CLI：

```bash
npx supabase login
npx supabase link --project-ref nyqjjsuzxwxufauqoqvw
npx supabase secrets set STRIPE_SECRET_KEY=sk_test_...
npx supabase secrets set CHARACTER_PASS_PRICE_ID=price_1TucdGIe5ZqA9rXhhXYsavB1
```

### 2. Deploy Edge Functions

在含 `supabase/` 的目錄：

```bash
npx supabase functions deploy get-entitlements
npx supabase functions deploy create-checkout
npx supabase functions deploy stripe-webhook --no-verify-jwt
```

`stripe-webhook` **必須** `--no-verify-jwt`（Stripe 不帶 Supabase JWT）。

### 3. Stripe Webhook（Test mode）

1. Stripe Dashboard（Test）→ Developers → Webhooks → Add endpoint  
2. URL：`https://<PROJECT_REF>.supabase.co/functions/v1/stripe-webhook`  
3. Event：`checkout.session.completed`  
4. 複製 Signing secret `whsec_...` → Supabase Secret `STRIPE_WEBHOOK_SECRET`  
5. 可再 deploy 一次 `stripe-webhook`

### 4. 遊戲內測試

1. 綁定 Email（Guest 不能結帳）  
2. Profile → **解鎖全部武將** → Stripe Checkout  
3. 測試卡：`4242 4242 4242 4242`  
4. 回跳後頂欄 PASS、T1–T3 可出陣
